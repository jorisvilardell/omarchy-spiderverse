# Spiderverse Omarchy theme

Indigo/violet base, magenta accent, cyan/red glitch-split accents --
`colors.toml` + `shell.toml` for the standard Omarchy palette, plus a
`hyprland.lua` with a two-stop gradient border and punchier "comic panel
pop" window animations (Omarchy Quattro's Lua config, not legacy hyprlang).

## Install

Omarchy discovers themes by folder name under `~/.config/omarchy/themes/`:

```bash
cp -r theme ~/.config/omarchy/themes/spiderverse
omarchy theme spiderverse   # or pick it from the theme picker
```
